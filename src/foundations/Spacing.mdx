# Spacing

Escala en múltiplos de 4 y cuatro roles: **inset** (relleno), **stack** (vertical), **inline** (horizontal) y **gutter** (columnas). El rol se mantiene; el valor se adapta a la densidad (compact / regular / expanded). Criterio completo en `foundations/kia-spacing-tokens.md`.

En RN: `const { space } = useTheme(); space['inset/md']`.
